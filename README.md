# Saathi – Elder People Pram

## 🧩 Problem Statement

**Title:** Innovative Gerontological Care Solutions  
Design smart products to improve mobility, safety, and healthcare access for the elderly population.

---

## 🛠️ Project Overview

**Saathi** is a smart, assistive pram designed for elderly individuals to improve mobility, monitor health, and stay connected with caregivers in real-time. It integrates IoT-based vitals tracking, GPS location, a medicine dispenser, and predictive health algorithms into a user-friendly, mobile device.

---

## ⚙️ Key Features

- **🦽 Elder Pram Mobility Aid:**  
  Four-wheel stable design with back support for safe walking and reduced fall risk.

- **💊 Smart Medicine Dispenser:**  
  App-controlled system to schedule and track medication intake remotely.

- **🩺 Vitals Monitoring Band:**  
  Continuously tracks vital health parameters like heart rate, temperature, etc.

- **📍 GPS Tracking via LoRa:**  
  Real-time location sharing with caregivers using low-power LoRa communication.

- **🧠 Health Prediction Engine:**  
  Uses real-time data to analyze trends and suggest medications for caregiver approval.

- **📲 Mobile App Integration:**  
  Manages vitals, medications, GPS, and two-way communication between elders and caregivers.

---

## 🚀 Impact

- **Improved Elder Independence:** Encourages freedom and autonomy in daily activities.
- **Better Health Monitoring:** Enables early detection of health issues through continuous data analysis.
- **Reduced Healthcare Burden:** Prevents emergencies with proactive health management.
- **Convenience for Caregivers:** Remote access saves time and resources.
- **Cost-Effective Alternative:** Affordable solution for a wide demographic.

---

## 🔬 Technical Approach

| Component              | Description                                                                 |
|------------------------|-----------------------------------------------------------------------------|
| Elder Pram             | Lightweight, four-wheel, stable design with ergonomic support.              |
| LoRa Technology        | Enables long-range, low-power GPS-based tracking.                           |
| Health Band            | Monitors vital signs and sends data to the system in real time.             |
| Mobile Application     | Developed for Android/iOS to facilitate monitoring and control.             |
| Predictive Algorithms  | Suggests health recommendations based on trends in sensor data.             |

---

## 📈 Feasibility and Scalability

- **Affordable Components**: Uses cost-effective health bands, sensors, and GPS modules.
- **Proven Technologies**: LoRa, health sensors, and app-based ecosystems are well-tested.
- **Battery Efficient**: LoRa ensures low power consumption for long usage.
- **Cloud Integration Ready**: Scalable architecture for multiple users and locations.
- **Mass Production Friendly**: Designed using modular, standardized, low-cost parts.
